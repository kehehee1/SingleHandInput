# 左手单手输入工具

基于 AutoHotkey v2 的左手单手输入方案——**单击原键，双击对称键**。

## 快速开始

1. 下载安装 [AutoHotkey v2](https://www.autohotkey.com/download/)
2. 双击 `LeftHandSymmetry.ahk` 运行
3. 按 **Alt+R** 切换单手模式

## 使用方法

| 操作 | 效果 |
|---|---|
| 按 **Alt+R** | 开启/关闭单手模式 |
| 单击任意键 | 输出原键（正常打字） |
| 快速双击同一键（220ms 内） | 输出映射键（如双击 `a` → `Backspace`） |
| 右键托盘图标 | 自定义菜单（切换模式、预览、配置等） |

## 托盘菜单

启动后托盘图标右键菜单完全自定义，已移除 AutoHotkey 自带菜单：

| 菜单项 | 功能 |
|---|---|
| 切换单手模式 | 开启/关闭单手模式（快捷键 Alt+R） |
| 显示/隐藏预览窗口 | 切换预览窗口的显隐 |
| 切换预览模式 | 全键盘模式 ↔ 仅显示映射键模式 |
| 设置双击时间... | 调整双击判定灵敏度（毫秒） |
| 打开配置 | 用记事本打开 INI 配置文件 |
| 重置默认映射 | 恢复按键映射为默认值（需确认） |
| 重新加载配置 | 热加载 INI 配置变更，无需重启 |
| 打开脚本 | 用记事本打开 AHK 源文件 |
| 重启 | 重启脚本（重新加载全部代码） |
| 退出 | 退出脚本 |

## 预览窗口

开启单手模式后，屏幕右下角显示半透明预览窗口，采用**虚拟键盘样式**布局：

- **虚拟键盘布局**：左手区域按键按行排列（数字行、上排、中排、下排），每行居中
- **蓝色键帽**：有映射的按键，白色大字显示物理键名，底部小字显示映射目标键
- **灰色键帽**：无映射的按键，深色文字显示物理键名
- **按键高亮**：敲击按键时对应键帽显示为亮黄色，500ms 后恢复
- **鼠标悬浮**：悬浮在键帽上时文字放大为绿色，方便查看
- 支持 **鼠标左键拖动** 到任意位置，松开后自动保存位置
- **右键菜单**：调整透明度（50%/70%/90%）
- 窗口置顶、不抢焦点、半透明

### 两种预览模式

| 模式 | 说明 |
|---|---|
| **全键盘**（full） | 显示左手区域所有按键，有映射的蓝色、无映射的灰色 |
| **仅映射键**（mapped） | 只显示有映射关系的按键，隐藏无映射的灰色键帽 |

通过托盘菜单「切换预览模式」或在 INI 配置中设置 `PreviewMode` 切换。

## 对称映射规则

### 默认映射表

```
数字行:  1→0  2→9  3→8  4→7  5→6
上排:    q→p  w→o  e→i  r→u  t→y
中排:    a→Backspace  s→l  d→k  f→j  g→h
下排:    z→Enter  x→Delete  c→m  v→n  (b 不映射)
```

### 特殊键说明

| 物理键 | 单击 | 双击 |
|--------|------|------|
| `a` | a | Backspace（退格） |
| `z` | z | Enter（回车） |
| `x` | x | Delete（删除） |
| `b` | b | b（不映射，保持原样） |

## 配置说明

### INI 配置文件

配置文件 `LeftHandSymmetry.ini` 位于脚本同目录，支持手动编辑和注释，ANSI 编码（兼容 Windows IniRead/IniWrite API）。

#### [Settings] 节

| 参数 | 默认值 | 说明 |
|---|---|---|
| `DoubleClickTime` | 220 | 双击判定时间（毫秒），越小越灵敏 |
| `Transparency` | 220 | 窗口透明度（0=全透, 255=不透） |
| `SymmetryActive` | 0 | 单手模式激活状态（重启后自动恢复） |
| `PreviewVisible` | 0 | 预览窗口是否默认显示 |
| `PreviewMode` | full | 预览模式：`full`=全键盘，`mapped`=仅映射键 |
| `PreviewPosInitialized` | 0 | 预览窗口位置是否已初始化 |
| `PreviewX` / `PreviewY` | — | 预览窗口上次保存的位置 |

#### [KeyMapping] 节

自定义按键映射，格式：`原始键=目标键`

```ini
[KeyMapping]
; 左手单手输入工具 - 按键映射配置
; 格式：原始键=目标键（双击原始键时发送目标键）
; 例如：a=l 表示双击 a 发送 l（单次 a 仍透传原键）
; 目标键可用键名：Backspace, Enter, Delete, Tab, Esc, Space 等

a=Backspace
s=l
d=k
```

- 删除 `[KeyMapping]` 节后重启脚本会自动重建带注释的默认配置
- 通过托盘菜单「打开配置」可直接编辑
- 编辑后通过菜单「重新加载配置」热加载，无需重启

### 脚本顶部参数

也可直接在 `LeftHandSymmetry.ahk` 顶部修改：

```autohotkey
global DOUBLE_CLICK_TIME := 220        ; 双击判定时间（毫秒）
global SYMMETRY_HOTKEY := "Alt+R"      ; 切换单手模式的热键
global TRANSPARENCY := 220             ; 窗口透明度（0=全透, 255=不透）
```

## 状态持久化

脚本启动时自动从 `LeftHandSymmetry.ini` 恢复以下状态：

- **单手模式**：关闭时若开启，重启后自动激活单手模式，无需手动切换
- **预览窗口**：关闭时若显示，重启后自动显示预览窗口
- **预览模式**：保留上次选择的 `full`（全键盘）或 `mapped`（仅映射键）模式
- **窗口位置**：拖动预览窗口后自动保存位置，重启后保持原位

每次切换单手模式、显示/隐藏预览窗口、切换预览模式时，自动保存配置到 INI 文件。

## 组合键兼容

开启单手模式时，按住 **Ctrl/Alt/Shift/Win** 时按键正常穿透，不影响组合键使用。

## 冲突规避

与 pet 工具（Space/CapsLock 模式）自动兼容——Space 按下或 CapsLock 激活时，单手模式自动让 pet 接管。

## 推荐搭配工具

本工具与其他效率工具配合使用，效果更佳：

### [Pet](https://github.com/majorworld/Pet) — 输入增强工具

- 提供 **Space 增强菜单** 和 **CapsLock 快捷键** 功能
- 单手输入 + Pet 相得益彰：单手负责键盘输入，Pet 负责快速触发命令/符号
- 本工具已内置与 Pet 的冲突规避逻辑，两者可同时运行互不干扰

### StrokeIt — 鼠标手势工具

- 通过鼠标手势替代高频操作，减少右手离开鼠标的频率
- 推荐手势示例：

  | 手势 | 功能 |
  |------|------|
  | 右→左 | 关闭标签页（Ctrl+W） |
  | 右→左→右 | 恢复标签页（Ctrl+Shift+T） |
  | 上→下 | 最小化窗口 |
  | 下→上 | 最大化/还原窗口 |
  | 左→右 | 前进（Alt+→） |
  | 右→左 | 后退（Alt+←） |

- 三者结合：左手键盘输入 + Pet 快速命令 + StrokeIt 鼠标手势，单手操作极限效率

## 编译为独立 exe

安装 AutoHotkey 后，使用自带的 `Ahk2Exe` 工具：

```
Ahk2Exe.exe /in LeftHandSymmetry.ahk /out LeftHandSymmetry.exe
```

编译后无需安装 AHK 即可运行。
